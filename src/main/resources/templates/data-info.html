자료와 비교 기준

위치를 확인하고, 부족한 정보도 함께 봐요

시설이 많다고 안전한 길로 판정하지 않아요. 지도에 표시가 없어도 실제 시설이나 위험이 없다는 뜻은 아니에요.

후보 길 비교하기
먼저 살펴볼 길을 고르는 기준

빠른 길보다 2분 이내로 더 걸리는 후보에서 사고 영역 겹침, 신호 미확인 건넘, 뚜렷한 범죄 자료 차이, 건넘 수를 차례로 비교해요. 차이가 같으면 예상 시간과 거리로 골라요.

후보가 하나면 우열을 비교하지 않아요. 모든 후보는 직접 선택할 수 있어요.

지도·장소 검색·길 안내에도 다른 데이터를 써요
네이버 지도 / VWorld 지도
배경 지도와 지도 조작에 사용해요. 배경 지도만으로 안전 등급을 계산하지 않아요. 설정·연결 상태에 따라 대체 지도를 사용해요.
네이버 지역 검색·Geocoding / VWorld 검색
장소·주소와 좌표를 찾아요. 네이버 검색 결과가 없으면 VWorld로 보완해요.
TMAP 보행자 경로
후보 경로선, 예상 시간·거리, 건넘·회전 정보를 받아 비교와 안내에 사용해요.
한국도로교통공단 사고 자료
어린이 보행·어린이보호구역 내 어린이·노인 보행 사고다발영역을 경로와 대조해요. 지도 표시와 후보 제안에 반영해요.
생활안전지도 범죄 자료
공식 등급 지도와 경로를 대조해요. 등급 표시 없음·판독 불가·조회 실패를 구분하며, 의미가 확인되지 않은 빈 영역을 낮은 등급으로 계산하지 않아요.
기기의 현재 위치
위치 찾기·안내 진행·이탈·도착 판단에 사용해요. 현재 GPS 위치는 브라우저에서 처리해요.
AI 안내문 (Groq·Gemini)
확정된 안내 지점 정보를 쉬운 문장으로 바꿔요. 안전 등급이나 새 시설을 생성하지 않아요. 실패하면 정해진 안내문을 사용해요.
사고·범죄 자료의 의미

사고 영역은 과거 사고다발지역과 경로의 겹침이에요. 서로 겹치는 영역이 있어 실제 장소 수와 다를 수 있어요. 화면의 자료 연도를 확인해 주세요.

범죄는 생활안전지도·경찰청의 1~10등급 지도에서 7~10등급과 겹치는 길이를 5m 간격으로 근사해요. 현재 위험도나 범죄 확률이 아니에요. 모든 후보의 확인 비율이 90% 이상이며 미확인 범위를 고려해도 차이가 뚜렷할 때만 제안에 반영해요.

제공기관은 수집연도 2025년·수정일 2025-12-29로 안내해요. 실제 사건의 집계 시작·종료일과 응답 지도 버전은 미확인이에요. 보호구역 경계와 신호 연결도 현장 확인이 필요해요.

경로와 연결 방향이 분명히 맞는 갈림길만 안내 지점으로 사용해요. 공사·통행 제한과 실제 길은 현장에서 확인해 주세요.
