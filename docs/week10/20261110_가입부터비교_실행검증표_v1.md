# 10주차 가입부터 후보 비교 실행 검증

2026년 11월 10일에 유준서가 작성한 시험표 14개 항목을 Codex가 민채의 로컬 환경에서 실행했다. 팀 저장소 main `7cc3d7e`를 기준으로 1차 실행하고, 후보 조회 화면의 401 처리 수정 후 동일 조건으로 전 항목을 다시 실행했다. Java 21, H2, 중랑구 개발 표본 10건을 사용했다. 일반 시험은 8081, TMAP 키 없는 시험은 별도 18082 서버에서 실행했다.

**최종 결과는 14개 통과다.** 1차 실행에서는 13개 통과, 1개 실패였다. 로그아웃 뒤 후보 요청의 401 응답을 화면에서 처리하도록 수정한 뒤 C-6이 통과했다. [팀 저장소 원본 시험표](https://github.com/minch05/safe-school-road-team/blob/7cc3d7e300f7e6284d0a11a92cda868b1e465c97/20261104_가입부터비교_테스트결과_v1.md)

C-6 재현 순서는 로그인 → 상단 로그아웃 → 첫 화면에서 유효한 기본 좌표로 ‘실제 보행 경로 찾기’ 선택이다. 1차에서는 `week9-map.js`가 빈 401 응답을 JSON으로 해석해 오류가 났다. 401을 먼저 확인해 로그인 화면으로 이동하도록 바꿨다. 같은 순서로 재시험해 `/login.html` 이동을 확인했다.

별도로 RGN6-122의 시설 범위 조회 자동 시험 4개가 통과했다. 표본 근처 조회, 서울 밖 조회, 다른 구 조회, 동일 표본 재적재 후 중복 방지를 확인했다. RGN6-123의 실행표 결과는 위 표를 근거로 기록한다.

수정 후 Java 22개와 안내 로직 JavaScript 8개가 통과했고 실행 파일 빌드에 성공했다. 예시 생성용 Java 시험 1개는 조건부로 건너뛰었다.
