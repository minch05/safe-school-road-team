별도로 RGN6-122의 시설 범위 조회 자동 시험 4개가 통과했다. 표본 근처 조회, 서울 밖 조회, 다른 구 조회, 동일 표본 재적재 후 중복 방지를 확인했다. RGN6-123의 실행표 결과는 위 표를 근거로 기록한다.

## 10주차 구현 항목 추가 재검증

2026-11-10, Java 21과 새 데이터 폴더의 독립 MySQL 8.4.13(127.0.0.1:13306)에서 수정본을 확인했다. 기존 DB와 분리했다. 위 14개 시험의 H2 개발 표본 환경과 구분한다.
