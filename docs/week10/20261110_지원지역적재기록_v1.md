## 1. 지원 범위

서울 12개 구를 지원한다: 강서구, 광진구, 동대문구, 중랑구, 관악구, 강북구, 구로구, 성북구, 종로구, 영등포구, 양천구, 중구.

중랑구를 기준 구로 삼아 먼저 검증했다(아래 4절). 나머지 11개 구도 같은 규칙으로 적재했고, 자료가 없는 칸은 `data_coverage`에 `NO_DATA`(화면 표시는 '자료 부족')로 기록한다.

## 5. 신호 정보

- 확정(`CONFIRMED`) 자료는 없다. 횡단보도의 신호 상태는 둘뿐이다.
  - 추정(`ESTIMATED`) 5,622건: 보행 신호 위치와 연결된 횡단보도
  - 미확인(`UNKNOWN`) 18,594건: 연결하지 못한 횡단보도. **기본값이며 '신호 없음'이라는 뜻이 아니다**
- 화면·안내문은 신호가 있다고 가정하지 않는다('초록불이면 건너요' 같은 말 금지).
- 횡단보도가 아닌 자료에는 신호 값을 넣지 않는다(시험으로 확인).

## 6. 적재하지 않은 행과 한계

- 좌표가 없거나 잘못된 원본 행은 넣지 않았다: CCTV 12행, 안전비상벨 16행. 구를 알 수 없어서 구별 표에는 들어가지 않는다.
- 보안등: 원본에서 12개 구 좌표 행을 얻지 못해 0건이다. 화면은 '자료 부족'으로 보여 준다.
- 어린이보호구역은 대상시설 위치(점)만 있다. 근거 분석은 이 점에서 300m 안을 참고 값으로 보고, '실제 구역 경계가 아니에요'라고 함께 알린다.
- 안전비상벨 13,943건 중 9,311건이 CCTV와 좌표가 정확히 같다. 같은 기둥에 함께 달린 설비로 보이며, 근거에서는 종류별로 따로 센다.
- 시설의 작동 여부와 현재 상태는 확인하지 않았다.
- 종로구 안전비상벨은 89건으로 다른 구보다 크게 적다. 원본 자체가 적은 것인지 4-11-03 결과표 작성 때 원본 행 수와 함께 확인한다.

## 7. 다시 적재하는 방법

```bash
# 1) 원본에서 적재 파일 만들기 (원본 위치·옵션은 스크립트 도움말)
python3 scripts/prepare_supported_data.py --help
# 2) 서버 실행과 함께 적재
./gradlew bootRun --args='--import-supported-data'
# 3) 확인
curl -s http://localhost:8081/api/data/coverage   # 로그인 세션 필요
python3 scripts/district_counts.py --coverage-json coverage.json --out build/district-counts
```
