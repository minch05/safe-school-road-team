## 한계

- 기본 H2 DB는 서버를 끄면 가입 정보가 사라지므로, 모든 브라우저 시험은 서버를 켠 채로 한 번에 진행했다.
- TMAP 키가 없는 컴퓨터에서는 실제 후보 경로 조회를 확인하지 않는다. 5번은 로그인하지 않은 상태의 차단(401)과 화면 안내만 본다.
- 로컬 개발용 시험이며 HTTPS 배포 환경과 휴대폰 브라우저 결과는 포함하지 않는다.
