① 홈 화면에 설치하기

아이폰(사파리): 공유 버튼 → "홈 화면에 추가"
안드로이드(크롬): 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"
아이폰은 설치한 앱 안에서 한 번 더 로그인해야 해요. (사파리와 로그인 상태가 따로예요)

② 위치와 알림 허용하기

위치를 허용하면 지도에서 내 위치를 볼 수 있어요. 위치는 서버로 보내지 않아요.
보호자는 설정에서 알림을 등록해 주세요. 보호자와 연동된 아이가 출발·도착을 기록하면 알림을 보내요. 예상 도착 시간보다 15분이 지나도 도착 기록이 없으면 확인 알림을 보내요. 이것만으로 사고가 났다고 판단하지 않아요. 아이폰은 iOS 16.4 이상에서 홈 화면에 설치해야 받을 수 있어요.

기기 권한이나 네트워크 때문에 알림이 늦거나 오지 않을 수 있어요. 알림이 없으면 홈의 아이 상세에서 출발·도착 기록을 확인하고, 필요하면 아이에게 직접 연락해 주세요.

③ 걸을 때는 앞을 보고 걸어요

폰은 길이 헷갈릴 때만 꺼내 보세요. 화면을 보면서 걸으면 차나 자전거를 못 볼 수 있어요.
화면이 켜져 있을 때만 위치를 읽을 수 있어서, 폰을 넣고 걸으면 자동으로 도착을 알아채지 못해요. 도착하면 "도착했어요" 버튼을 꼭 눌러 주세요.

④ 경로를 고를 때는 이유와 위치를 함께 봐요

제안된 길의 이유를 펼쳐 보고, 비교표의 위치 버튼으로 건너는 곳과 사고 자료를 지도에서 확인해요. 참고할 시설이 많다는 이유만으로 더 안전하다고 판단하지 않아요.

내 위치는 서버로 보내지 않아요. 보호자에게는 "출발함 / 도착함"만 전달돼요.
지도에 없다고 시설이 없다는 뜻은 아니에요. 지역과 자료마다 확보 범위가 달라요. 횡단보도 신호가 "미확인"이면 신호 유무를 확인할 자료가 부족하다는 뜻이에요. "신호 있음 추정"도 꼭 멈춰서 직접 확인해요.
